## 📝 ALTERNATIVA: Agregar campos al modelo

Si quieres usar filtros por edad, agrega estos campos:

```python
# En apps/grupos/models.py - Modelo GrupoTerapeutico
class GrupoTerapeutico(models.Model):
    # ... campos existentes ...
    
    # Agregar estos campos:
    edad_minima = models.IntegerField(
        'Edad Mínima',
        null=True,
        blank=True,
        help_text='Edad mínima recomendada'
    )
    edad_maxima = models.IntegerField(
        'Edad Máxima',
        null=True,
        blank=True,
        help_text='Edad máxima recomendada'
    )
```

Luego ejecutar:
```bash
python manage.py makemigrations
python manage.py migrate
```
