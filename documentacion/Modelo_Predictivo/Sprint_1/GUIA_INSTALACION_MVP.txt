
### PASO 4: Configurar URLs (3 minutos)

Abrir: **apps/grupos/urls.py**

Agregar al inicio del archivo:

```python
# Importar vistas del recomendador
from .views_recomendador import (
    recomendar_grupos_paciente,
    asignar_desde_recomendacion,
    exportar_recomendaciones,
    debug_recomendacion
)
```

Agregar al `urlpatterns`:

```python
urlpatterns = [
    # ... URLs existentes ...
    
    # ========== SISTEMA DE RECOMENDACIÓN (NUEVO) ==========
    path(
        'paciente/<int:paciente_id>/recomendar-grupos/',
        recomendar_grupos_paciente,
        name='recomendar_grupos_paciente'
    ),
    path(
        'paciente/<int:paciente_id>/asignar-grupo/<int:grupo_id>/',
        asignar_desde_recomendacion,
        name='asignar_desde_recomendacion'
    ),
    path(
        'paciente/<int:paciente_id>/exportar-recomendaciones/',
        exportar_recomendaciones,
        name='exportar_recomendaciones'
    ),
    path(
        'debug/paciente/<int:paciente_id>/grupo/<int:grupo_id>/',
        debug_recomendacion,
        name='debug_recomendacion'
    ),
]
```

### PASO 7: Verificar Modelos Requeridos (2 minutos)

El sistema necesita estos campos en tus modelos:

**Modelo Paciente** (apps/procedimientos/models.py):
- ✅ edad (property o field)
- ✅ genero (CharField)
- ✅ fecha_nacimiento (DateField)
- ✅ nombre_completo (property o field)

**Modelo GrupoTerapeutico** (apps/grupos/models.py):
- ✅ estado (CharField) - debe tener opción 'ACTIVO'
- ✅ edad_minima (IntegerField)
- ✅ edad_maxima (IntegerField)
- ✅ cupos_disponibles (property o field)
- ✅ capacidad_maxima (IntegerField)
- ✅ terapia (ForeignKey a Terapia)
- ✅ fecha_inicio (DateField) - opcional
- ⚠️  nivel_funcionamiento (CharField) - opcional pero recomendado
- ⚠️  areas_enfoque (TextField) - opcional pero recomendado

**Modelo Valoracion** (apps/procedimientos/models.py):
- ✅ paciente (ForeignKey)
- ✅ fecha_valoracion (DateField)
- ✅ diagnostico_principal (CharField/TextField)
- ⚠️  nivel_funcionamiento (CharField) - opcional pero recomendado
- ⚠️  areas_afectadas (TextField) - opcional pero recomendado

**Modelo AsignacionGrupo** (apps/grupos/models.py):
- ✅ paciente (ForeignKey)
- ✅ grupo (ForeignKey)
- ✅ estado (CharField) - debe tener 'ACTIVA', 'FINALIZADA'
- ✅ fecha_inicio (DateField)
- ⚠️  fecha_fin (DateField) - opcional

Si falta algún campo opcional, el sistema funcionará pero con menos precisión.

## 🔧 SOLUCIÓN DE PROBLEMAS

### Error: "ModuleNotFoundError: No module named 'apps.ml_models'"

**Solución:**
```bash
# Verificar que existe el __init__.py
ls apps/ml_models/__init__.py

# Si no existe, crearlo
touch apps/ml_models/__init__.py

# Reiniciar servidor
```

### Error: "NoReverseMatch at /pacientes/1/ ... recomendar_grupos_paciente"

**Solución:**
```python
# Verificar que las URLs están en apps/grupos/urls.py
# Verificar que el namespace es 'grupos' en el include principal

# En tea_management/urls.py debe estar:
path('grupos/', include('apps.grupos.urls', namespace='grupos')),
```

### Error: "Paciente no tiene valoración"

**Solución:**
- Crear una valoración para el paciente primero
- O comentar la verificación en views.py temporalmente

### No aparecen grupos

**Solución:**
```bash
# Verificar que hay grupos activos
python manage.py shell
>>> from apps.grupos.models import GrupoTerapeutico
>>> GrupoTerapeutico.objects.filter(estado='ACTIVO').count()

# Si es 0, crear grupos de prueba o cambiar estado
```

### Score siempre sale bajo

**Solución:**
```python
# Ajustar pesos en apps/ml_models/scoring.py
# O crear un método para ajustar pesos dinámicamente

# Ejemplo: dar más peso a disponibilidad
PESOS = {
    'edad': 0.30,
    'disponibilidad': 0.35,  # Aumentado
    'nivel': 0.15,
    # ...
}
```
