## ❌ ERROR #1: NoReverseMatch - paciente_detail

**Error:** 
```
NoReverseMatch: Reverse for 'paciente_detail' with keyword arguments 
'{'paciente_id': 12}' not found
```

**Causa:** URL espera `pk`, no `paciente_id`

**Solución:**
```python
# views_recomendador.py - Líneas 66 y 157
# Cambiar:
return redirect('procedimientos:paciente_detail', paciente_id=paciente_id)
# Por:
return redirect('procedimientos:paciente_detail', pk=paciente_id)
```
