## 🎯 ¿QUÉ HACE ESTE SPRINT?

Implementa el nuevo flujo de admisión y valoración de pacientes:

```
ADMISIÓN → VALORACIÓN INICIAL → PENDIENTE ASIGNACIÓN
```

### Funcionalidades:
- ✅ Admitir pacientes con número de admisión manual
- ✅ Capturar firma digital del acudiente
- ✅ Realizar valoración inicial completa
- ✅ Registrar problemas detectados
- ✅ Recomendar terapias
- ✅ Gestionar estados del paciente

## ⚡ INSTALACIÓN RÁPIDA (15 MINUTOS)

### 1. Leer la Guía
**Abrir:** `SPRINT1_INSTALACION_RAPIDA.txt`

### 2. Modificar Archivos
Copiar el código de la carpeta `1_codigo/` a tu proyecto:
- Modificar: `apps/procedimientos/models.py`
- Modificar: `apps/procedimientos/forms.py`
- Modificar: `apps/procedimientos/views.py`
- Modificar: `apps/procedimientos/urls.py`

### 3. Copiar Templates
Copiar archivos de `2_templates/` a:
```
tu_proyecto/templates/procedimientos/
```

### 4. Crear Migraciones
```bash
python manage.py makemigrations
python manage.py migrate
```

### 5. ¡Listo!
```bash
python manage.py runserver
```

## 🐛 SOLUCIÓN DE PROBLEMAS

### Error: "numero_admision cannot be null"
**Solución:** Usar el script de migración
```bash
python manage.py shell
>>> exec(open('1_codigo/SPRINT1_SCRIPT_MIGRACION.py').read())
>>> migrar_pacientes_existentes()
```

### Error: "estado value too long"
**Solución:** Aumentar max_length del campo estado a 30 en models.py

### Más problemas:
Ver sección completa en `3_documentacion/SPRINT1_GUIA_COMPLETA.md`
