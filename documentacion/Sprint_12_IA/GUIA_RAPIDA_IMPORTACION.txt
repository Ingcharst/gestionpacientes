# GUÍA RÁPIDA: IMPORTACIÓN DE DATOS PARA IA

## 🎯 OBJETIVO
Cargar datos históricos de la clínica al sistema para entrenar modelo de IA.

## 📋 PASOS (30 minutos)

### PASO 1: PREPARAR TUS DATOS
1. Exporta datos de tu sistema actual a Excel/CSV
2. Descarga las plantillas:
   - plantilla_pacientes.csv
   - plantilla_valoraciones.csv
   - plantilla_grupos.csv
   - plantilla_asignaciones.csv

### PASO 2: LLENAR PLANTILLAS
Usa las plantillas como guía, reemplaza datos de ejemplo con datos reales:

**plantilla_pacientes.csv:**
- Nombres, apellidos, documento, fecha nacimiento
- Diagnóstico principal
- Datos de contacto

**plantilla_valoraciones.csv (CRÍTICO PARA IA):**
- Documento del paciente
- Diagnóstico CIE-10 (F84.0, F80.1, F90.0, etc.)
- Nivel funcionalidad (INDEPENDIENTE/SEMI_DEPENDIENTE/DEPENDIENTE)
- Problemas detectados en JSON (copiar formato exacto)

**plantilla_grupos.csv:**
- Nombre del grupo
- Código terapia (FONO, TO, PSICO, INTEGRAL)
- Capacidad, horarios, días

**plantilla_asignaciones.csv (CRÍTICO PARA IA):**
- Documento paciente + nombre grupo
- Número de terapias asignadas
- Fechas, días de asistencia

### PASO 4: COPIAR ARCHIVOS
Copiar las 4 plantillas CSV llenas + script a la raíz del proyecto:
```
/tea_management/
  ├── manage.py
  ├── plantilla_pacientes.csv        ← AQUÍ
  ├── plantilla_valoraciones.csv     ← AQUÍ
  ├── plantilla_grupos.csv           ← AQUÍ
  ├── plantilla_asignaciones.csv     ← AQUÍ
  └── import_datos_ia.py             ← AQUÍ
```

### PASO 5: EJECUTAR IMPORTACIÓN
```bash
python manage.py shell < import_datos_ia.py
```

O manualmente:
```bash
python manage.py shell
exec(open('import_datos_ia.py').read())
```

## ⚠️ ERRORES COMUNES

**"Paciente no encontrado":**
→ El documento en valoraciones/asignaciones no coincide con pacientes

**"Terapia no encontrada":**
→ Código de terapia incorrecto (usar: FONO, TO, PSICO, INTEGRAL)

**"JSON decode error":**
→ Formato de JSON incorrecto en problemas_detectados o días

**"Usuario no existe":**
→ Crear usuario 'sistema' primero (Paso 3)
