# ⚡ GUÍA RÁPIDA - CORRECCIÓN FORMULARIOS QUE NO GUARDAN

## 🎯 PROBLEMA
Los formularios de **Crear Procedimiento** y **Crear Sesión Terapéutica** no guardaban datos.

## ✅ SOLUCIÓN EN 3 PASOS (5 MINUTOS)

### PASO 1: Reemplazar Archivos (3 min)

```
ORIGEN (outputs/)                    → DESTINO (tu proyecto)
═══════════════════════════════════════════════════════════════

procedimientos_forms.py              → apps/procedimientos/forms.py
procedimientos_models.py             → apps/procedimientos/models.py  
procedimientos_views_corregido.py    → apps/procedimientos/views.py
procedimiento_form.html              → templates/procedimientos/form.html
sesion_form.html                     → templates/procedimientos/sesion_form.html
```

### PASO 2: Reiniciar Servidor (1 min)

```bash
# Detener servidor (Ctrl+C)
# Iniciar nuevamente
python manage.py runserver
```

### PASO 3: Probar (1 min)

**Procedimiento:**
1. Ir a `/procedimientos/crear/`
2. Llenar: Paciente, Tipo, Profesional, Fecha, Hora, Motivo, Costo
3. Click "Guardar"
4. ✅ Debe mostrar mensaje de éxito y redirigir

**Sesión:**
1. Ir a `/procedimientos/sesiones/crear/`
2. Llenar: Paciente, Terapia, Terapeuta, Fecha, Hora, Duración, Costo, Objetivos, Actividades
3. Click "Guardar"
4. ✅ Debe mostrar mensaje de éxito y redirigir

## ⚠️ REQUISITOS PREVIOS

Para que los formularios funcionen, necesitas:

1. ✅ **Pacientes** creados en el sistema
2. ✅ **Terapias** en el catálogo
3. ✅ **Usuarios** con rol TERAPEUTA/MEDICO/PSICOLOGO
4. ✅ **Consultorios** (opcional)

Si los selectores muestran "--------", es porque faltan estos datos.

## 🐛 SOLUCIÓN DE PROBLEMAS

### "This field is required"
→ Llenar todos los campos con asterisco rojo (*)

### Selectores vacíos
→ Crear pacientes/terapias/usuarios primero

### Error al guardar
→ Revisar logs del servidor: `python manage.py runserver`
