## ⚠️ PROBLEMAS COMUNES

### Problema: Migraciones con conflictos
```bash
# Solución:
python manage.py makemigrations --merge
python manage.py migrate
```

### Problema: Pacientes no aparecen en grupos
```
Causa: Asignaciones sin admision_terapia
Solución: Eliminar y recrear asignaciones después del fix
```

### Problema: No permite asignar
```
Verificar:
1. Paciente tiene valoración completada
2. Admisión existe y está vigente
3. Fechas de admisión incluyen hoy
```
