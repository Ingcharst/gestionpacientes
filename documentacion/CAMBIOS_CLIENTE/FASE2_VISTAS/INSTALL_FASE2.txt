## CELERY (OPCIONAL)

Si tienes Celery configurado:

1. En proyecto/celery.py agregar tarea:
```python
from celery.schedules import crontab

app.conf.beat_schedule = {
    'verificar-inasistencias': {
        'task': 'apps.alertas.tasks.verificar_inasistencias_diarias',
        'schedule': crontab(hour=20, minute=0),  # 8 PM diario
    },
}
```

Si NO tienes Celery, crear comando Django:
```bash
# apps/alertas/management/commands/verificar_inasistencias.py
from django.core.management.base import BaseCommand
from apps.alertas.utils import GestorAlertas

class Command(BaseCommand):
    def handle(self, *args, **options):
        gestor = GestorAlertas()
        alertas = gestor.verificar_inasistencias()
        self.stdout.write(f'✓ {len(alertas)} alertas')

# Ejecutar con cron:
# 0 20 * * * cd /ruta/proyecto && python manage.py verificar_inasistencias
```
