# 🔧 FIX RÁPIDO: Error al Asignar desde Recomendaciones

## 🎯 PROBLEMA

Cuando haces clic en **"Asignar a este grupo"** desde recomendaciones:
```
❌ NoReverseMatch
❌ 'asignar_paciente_grupo' not found
```

---

## ⚡ SOLUCIÓN EN 2 MINUTOS

### PASO 1: Abrir el archivo

**Archivo:** `apps/grupos/views.py`

---

### PASO 2: Buscar la función

**Buscar con Ctrl+F:** `asignar_desde_recomendacion`

Encontrarás algo como:

```python
def asignar_desde_recomendacion(request, paciente_id, grupo_id):
    # ... código ...
    
    # ❌ ESTA LÍNEA CAUSA EL ERROR:
    return redirect('grupos:asignar_paciente_grupo',
                    paciente_id=paciente_id,
                    grupo_id=grupo_id)
```

---

### PASO 3: Cambiar UNA línea

**BORRAR esta línea:**
```python
return redirect('grupos:asignar_paciente_grupo',
                paciente_id=paciente_id,
                grupo_id=grupo_id)
```

**PONER esta línea:**
```python
return redirect('grupos:detalle_grupo', pk=grupo_id)
```

---

### PASO 4: Guardar y probar

1. **Guardar** el archivo (Ctrl+S)
2. **Reiniciar** servidor Django (si estaba corriendo)
3. **Probar** desde recomendaciones

---

## 💡 EXPLICACIÓN

### ¿Por qué el error?

La vista intenta redirigir a una URL que **no existe**:
```python
'grupos:asignar_paciente_grupo'  ❌ NO EXISTE en urls.py
```

### Solución:

Redirigir a una URL que **SÍ existe**:
```python
'grupos:detalle_grupo'  ✅ SÍ EXISTE en urls.py
```
