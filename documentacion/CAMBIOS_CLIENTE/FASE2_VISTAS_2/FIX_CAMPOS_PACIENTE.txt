# CORRECCIÓN: CAMPOS FORMULARIO PACIENTE

## PROBLEMA
El formulario usa campos que tu modelo `Paciente` no tiene:
- acudiente_nombre
- acudiente_telefono
- nombre
- documento
- acudiente_parentesco

## SOLUCIÓN

### 1. IDENTIFICAR CAMPOS REALES

Ejecutar en shell:
```bash
python manage.py shell
```

```python
from apps.procedimientos.models import Paciente
# Ver todos los campos
for field in Paciente._meta.get_fields():
    print(f"{field.name} - {field.__class__.__name__}")
```

O más simple:
```python
print([f.name for f in Paciente._meta.get_fields()])
```

### 2. AJUSTAR FORMULARIO

Opción A - Usar todos los campos (temporal):
```python
class PacienteRegistroForm(forms.ModelForm):
    class Meta:
        model = Paciente
        fields = '__all__'
        exclude = ['numero_historia_clinica']  # Deprecado
```

Opción B - Especificar campos existentes:
```python
class PacienteRegistroForm(forms.ModelForm):
    class Meta:
        model = Paciente
        fields = [
            # USAR SOLO LOS CAMPOS QUE EXISTEN EN TU MODELO
            # Ejemplo común:
            'primer_nombre',  # o 'nombres'

            'segundo_apellido',

            'sexo',  # o 'genero'
            'codigo_enfermedad',  # Nuevo campo agregado
```

### 3. CAMPOS COMUNES EN MODELOS PACIENTE

Revisa cuáles tienes:

**Identificación:**
- tipo_identificacion / tipo_documento
- numero_identificacion / documento
- numero_documento

**Nombres:**
- primer_nombre, segundo_nombre
- primer_apellido, segundo_apellido
- nombres, apellidos
- nombre_completo

**Demográficos:**
- fecha_nacimiento
- sexo / genero
- edad (calculado)

**Contacto:**
- telefono / telefono_contacto
- celular
- email / correo
- direccion

**Acudiente:**
- acudiente (texto completo)
- responsable_nombre
- responsable_telefono
- contacto_emergencia

**Diagnóstico:**
- codigo_enfermedad (FK a CodigoCIE10) - NUEVO
- diagnostico
- observaciones

### 4. EJEMPLO AJUSTADO

Basado en campos típicos:

```python
# apps/procedimientos/forms.py

class PacienteRegistroForm(forms.ModelForm):
    class Meta:
        model = Paciente
        fields = [
            'tipo_identificacion',
            'numero_identificacion',
            'primer_nombre',
            'segundo_nombre',
            'primer_apellido',
            'segundo_apellido',
            'fecha_nacimiento',
            'sexo',
            'codigo_enfermedad',  # Nuevo
            'telefono',
            'direccion',
        ]
        widgets = {
            'fecha_nacimiento': forms.DateInput(attrs={'type': 'date'}),
        }
    
    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        # Aplicar form-control
        for field in self.fields.values():
            field.widget.attrs['class'] = 'form-control'
```
