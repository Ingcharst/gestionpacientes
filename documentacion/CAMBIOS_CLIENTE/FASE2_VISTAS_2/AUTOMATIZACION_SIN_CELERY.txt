# AUTOMATIZACIÓN ALERTAS SIN CELERY

## INSTALACIÓN COMANDO

### 1. Crear estructura
```bash
mkdir -p apps/alertas/management/commands
touch apps/alertas/management/__init__.py
touch apps/alertas/management/commands/__init__.py
```

### 2. Copiar comando
```bash
cp comando_verificar_inasistencias.py apps/alertas/management/commands/verificar_inasistencias.py
```

### 3. Probar manualmente
```bash
python manage.py verificar_inasistencias
```

## AUTOMATIZACIÓN WINDOWS (Task Scheduler)

### Opción 1: Script BAT
```batch
@echo off
cd C:\ruta\a\tu\proyecto
call venv\Scripts\activate
python manage.py verificar_inasistencias
```

Guardar como: `verificar_alertas.bat`

### Opción 2: Programador de Tareas Windows

1. Abrir **Programador de tareas**
2. **Crear tarea básica**
3. Nombre: "Verificar Inasistencias TEA"
4. Desencadenador: **Diariamente** a las **20:00** (8 PM)
5. Acción: **Iniciar programa**
   - Programa: `C:\ruta\venv\Scripts\python.exe`
   - Argumentos: `manage.py verificar_inasistencias`
   - Iniciar en: `C:\ruta\proyecto`

### Configuración avanzada:
- ✅ Ejecutar aunque usuario no haya iniciado sesión
- ✅ Ejecutar con privilegios más altos
- ✅ Si falla, reintentar cada 10 minutos

## AUTOMATIZACIÓN LINUX (cron)

### 1. Editar crontab
```bash
crontab -e
```

### 2. Agregar línea
```bash
# Verificar inasistencias diariamente a las 8 PM
0 20 * * * cd /ruta/proyecto && /ruta/venv/bin/python manage.py verificar_inasistencias >> /var/log/alertas.log 2>&1
```

### 3. Verificar
```bash
crontab -l
```

## VERIFICACIÓN MANUAL (Panel Admin)

También puedes verificar desde el navegador:

1. Agregar URL en `apps/alertas/urls.py`:
```python
path('verificar/', views.forzar_verificacion, name='forzar_verificacion'),
```

2. Vista en `apps/alertas/views.py`:
```python
@login_required
def forzar_verificacion(request):
    """Forzar verificación manual"""
    if request.method == 'POST':
        gestor = GestorAlertas()
        alertas = gestor.verificar_inasistencias()
        messages.success(request, f'{len(alertas)} alertas generadas')
        return redirect('alertas:dashboard_alertas')
    return render(request, 'alertas/forzar_verificacion.html')
```

3. Acceder: `http://localhost:8000/alertas/verificar/`

## LOGS Y MONITOREO

### Guardar logs (opcional)
```python
# En apps/alertas/management/commands/verificar_inasistencias.py
import logging

logger = logging.getLogger(__name__)

def handle(self, *args, **options):
    logger.info('Iniciando verificación de inasistencias')
    alertas = gestor.verificar_inasistencias()
    logger.info(f'{len(alertas)} alertas generadas')
```

### Configurar en settings.py
```python
LOGGING = {
    'version': 1,
    'handlers': {
        'file': {
            'class': 'logging.FileHandler',
            'filename': 'logs/alertas.log',
        },
    },
    'loggers': {
        'apps.alertas': {
            'handlers': ['file'],
            'level': 'INFO',
        },
    },
}
```

## FRECUENCIAS RECOMENDADAS

- **Diaria (8 PM)**: Verificación principal
- **Opcional (12 PM)**: Verificación adicional
- **Fines de semana**: Desactivar si no hay sesiones
