# 🔴 PROBLEMA DETECTADO

## Error 1: NoReverseMatch (Línea 119)
**Archivo:** `pacientes_pendientes_valoracion.html`
**Error:** URL intenta pasar solo `paciente_id` pero requiere también `terapia_id`

```django
<!-- ❌ INCORRECTO (Línea 119): -->
<a href="{% url 'procedimientos:crear_valoracion' paciente.pk %}">

<!-- ✅ CORRECTO: -->
<a href="{% url 'procedimientos:valoraciones_paciente' pk=paciente.pk %}">
```

**Razón:** La vista `crear_valoracion` requiere AMBOS parámetros (paciente_id y terapia_id), pero el flujo correcto es ir primero a `valoraciones_paciente` donde el usuario selecciona la terapia.

## Error 2: Menús no existen
No hay enlaces en navbar para acceder a las nuevas funcionalidades.
