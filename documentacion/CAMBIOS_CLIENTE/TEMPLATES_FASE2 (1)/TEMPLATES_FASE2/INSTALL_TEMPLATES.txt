Copiar cada sección al archivo correspondiente según comentarios.

## DEPENDENCIAS

### CSS (ya incluido en templates):
- Bootstrap 5 Icons
- Select2 (solo registrar_paciente.html)

### Template Base:
Todos extienden `base/base.html`. Asegúrate que existe:
```django
{# base/base.html #}
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>{% block title %}TEA Management{% endblock %}</title>
    <link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css" rel="stylesheet">
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.0/font/bootstrap-icons.css">
    {% block extra_css %}{% endblock %}
</head>
<body>
    {% include 'base/navbar.html' %}
    
    <main>
        {% if messages %}
        <div class="container mt-3">
            {% for message in messages %}
            <div class="alert alert-{{ message.tags }} alert-dismissible fade show">
                {{ message }}
                <button type="button" class="btn-close" data-bs-dismiss="alert"></button>
            </div>
            {% endfor %}
        </div>
        {% endif %}
        
        {% block content %}{% endblock %}
    </main>
    
    <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
    <script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/js/bootstrap.bundle.min.js"></script>
    {% block extra_js %}{% endblock %}
</body>
</html>
```

## PERSONALIZACIÓN

### Cambiar colores tema:
En cada template buscar clases Bootstrap:
- `bg-primary` → `bg-success` (verde)
- `btn-primary` → `btn-info` (azul claro)

### Agregar logo IPS:
En base.html agregar:
```django
<img src="{% static 'img/logo.png' %}" alt="Logo">
```

## TROUBLESHOOTING

### Error: TemplateDoesNotExist
- Verificar estructura directorios
- Verificar nombre exacto del template
- Verificar que app esté en INSTALLED_APPS

### Error: url tag not found
- Verificar namespace en urls.py
- Ejemplo: `{% url 'procedimientos:registrar_paciente' %}`

### Estilos no cargan:
- Verificar CDN Bootstrap en base.html
- Limpiar cache navegador (Ctrl+F5)
