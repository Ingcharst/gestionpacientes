# 🔄 MIGRACIÓN: De ValoracionInicial a ValoracionProfesional

## 📊 CAMBIO EN LA ESTRUCTURA

### ANTES (Sistema viejo):
```python
# Un paciente → Una valoración inicial
ValoracionInicial (OneToOne)
- paciente.valoracion_inicial
- paciente.valoracion_inicial.completada
```

### AHORA (Sistema nuevo):
```python
# Un paciente → Múltiples valoraciones profesionales
ValoracionProfesional (ForeignKey)
- paciente.valoraciones_profesionales.all()
- valoracion.estado = 'COMPLETADA'
- Una por cada terapeuta/terapia
```

**REEMPLAZAR con:** Código de `validacion_actualizada.py`

**Cambios clave:**
```python
# ❌ ANTES:
if not hasattr(paciente, 'valoracion_inicial'):
    return False, 'Sin valoración', None

# ✅ AHORA:
valoracion = ValoracionProfesional.objects.filter(
    paciente=paciente,
    terapia=grupo.terapia,
    estado='COMPLETADA'
).first()

if not valoracion:
    return False, f'Sin valoración para {grupo.terapia.nombre}', None
```

## 📋 FLUJO CORRECTO ACTUALIZADO

```
1. REGISTRO
   → Estado: ADMITIDO
   
2. VALORACIONES PROFESIONALES
   → Cada terapeuta crea ValoracionProfesional
   → Estado valoración: COMPLETADA
   → Al completar primera → Paciente: PENDIENTE_ASIGNACION
   
3. ADMISIONES DE TERAPIA
   → Se crean AdmisionTerapia por cada terapia
   → Estado: VIGENTE
   → Vincula número EPS, fechas, cantidades
   
4. ASIGNACIÓN A GRUPOS
   → Requiere para ESA terapia:
     * ValoracionProfesional (COMPLETADA)
     * AdmisionTerapia (VIGENTE)
   → Crea AsignacionGrupo
   → Vincula admision_terapia
   → Estado paciente: ACTIVO
   
5. REGISTRO DE ASISTENCIAS
   → Incrementa cantidad_realizada
   → Al completar → Finaliza asignación automáticamente
   → Libera cupo del grupo
```
