## 💻 IMPLEMENTACIÓN TÉCNICA

### Lo que se agrega:

```python
# 1. VISTA (views.py)
def completar_todas_valoraciones(request, paciente_id):
    """Cambia estado a PENDIENTE_ASIGNACION"""
    
    paciente = get_object_or_404(Paciente, pk=paciente_id)
    
    # Verificar valoraciones
    valoraciones = ValoracionProfesional.objects.filter(
        paciente=paciente
    )
    
    if valoraciones.count() == 0:
        return error
    
    # Cambiar estado
    paciente.estado = 'PENDIENTE_ASIGNACION'
    paciente.save()
    
    return success

# 2. URL (urls.py)
path(
    'pacientes/<int:paciente_id>/valoraciones/completar/',
    views.completar_todas_valoraciones,
    name='completar_todas_valoraciones'
)

# 3. TEMPLATE (HTML)
<button onclick="completar({{ paciente.id }})">
    Completar
</button>

# 4. JAVASCRIPT
function completar(id) {
    if(confirm('¿Marcar como completo?')) {
        window.location.href = 
            `/procedimientos/pacientes/${id}/valoraciones/completar/`;
    }
}
```
