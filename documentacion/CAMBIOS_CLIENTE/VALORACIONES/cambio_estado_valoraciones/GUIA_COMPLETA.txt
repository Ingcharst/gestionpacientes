# 🔄 SOLUCIÓN: Cambio de Estado Después de Valoraciones

## 🎯 PROBLEMA IDENTIFICADO

**Síntoma:**
- Paciente JOSÉ ALBERTO SIERRA RODRIGUEZ tiene 5/5 valoraciones completadas
- Pero sigue apareciendo en "Pacientes Pendientes de Valoración"
- No puede ser asignado a grupos terapéuticos

**Causa:**
El sistema no tiene mecanismo para cambiar el estado del paciente de `PENDIENTE_VALORACION` a `PENDIENTE_ASIGNACION` después de completar todas las valoraciones.

---

## ✅ SOLUCIÓN IMPLEMENTADA

### Flujo completo:

```
1. Paciente ingresa → Estado: ADMITIDO
2. Terapeutas valoran → Estado: PENDIENTE_VALORACION
3. Todas valoradas → ✅ Asesor marca completo
4. Sistema cambia → Estado: PENDIENTE_ASIGNACION
5. Paciente listo para → Asignación a grupos
```

---

## 📦 COMPONENTES DE LA SOLUCIÓN

### 1. **Vista completar_todas_valoraciones**
- Verifica que el paciente tenga valoraciones
- Cambia estado a PENDIENTE_ASIGNACION
- Registra la acción

### 2. **Vista verificar_estado_valoraciones** (API)
- Retorna información de valoraciones
- Permite verificar antes de completar
- Muestra terapias y terapeutas

### 3. **Vista cambiar_estado_paciente** (General)
- Permite cambios de estado flexibles
- Con validación de estados permitidos
- Para uso futuro

### 4. **Botón "Completar Valoraciones"**
- En lista de pendientes
- En página de valoraciones
- Con confirmación inteligente

### PASO 4: Agregar JavaScript (1 min)

**En el mismo template**, agregar antes de `{% endblock %}`:

```html
{% block extra_js %}
<script>
function verificarYCompletar(pacienteId, nombrePaciente) {
    if(confirm(`¿Marcar valoraciones de ${nombrePaciente} como completadas?

El paciente pasará a "Pendiente de Asignación" y podrá ser asignado a grupos.`)) {
        window.location.href = `/procedimientos/pacientes/${pacienteId}/valoraciones/completar/`;
    }
}
</script>
{% endblock %}
```

## 🆘 TROUBLESHOOTING

### Problema: Botón no aparece

**Verificar:**
1. Template actualizado
2. JavaScript incluido
3. Cache limpiado (Ctrl+Shift+R)

---

### Problema: Error 404 al clic

**Verificar:**
1. URLs agregadas correctamente
2. Nombres coinciden: `completar_todas_valoraciones`
3. URL en JavaScript correcta

**Solución:**
```bash
# Ver URLs registradas
python manage.py show_urls | grep valoraciones
```

---

### Problema: Error "No permisos"

**Causa:** Usuario no es staff

**Solución:**
```python
# En Django Admin, marcar usuario como staff
user.is_staff = True
user.save()
```

O modificar verificación en `views.py`

---

### Problema: Paciente sigue en lista

**Verificar:**
1. Estado cambió en base de datos
2. Vista filtra correctamente
3. Cache limpiado

**Verificar en shell:**
```python
python manage.py shell
>>> from apps.procedimientos.models import Paciente
>>> p = Paciente.objects.get(id=17)
>>> p.estado
'PENDIENTE_ASIGNACION'  # ← Debe ser este
```
