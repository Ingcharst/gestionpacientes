# 🎯 RESUMEN EJECUTIVO - Fix Flujo de Pacientes

## 🔴 PROBLEMAS

1. **Pacientes no aparecen en "Pendientes de Valoración"**
   - Causa: Estado inicial es ACTIVO en vez de ADMITIDO
   
2. **Permite asignar a grupos sin valoración**
   - Causa: Falta validación en vistas de asignación
   
3. **Grupos vacíos aunque hay pacientes asignados**
   - Causa: Asignaciones sin admision_terapia vinculada

---

## ✅ SOLUCIONES (3 cambios)

### 1. Cambiar estado inicial (1 línea)
**Archivo:** `apps/procedimientos/models.py` línea ~292
```python
# DE:
default=Estado.ACTIVO,
# A:
default=Estado.ADMITIDO,
```

### 2. Establecer estado al admitir (1 línea)
**Archivo:** `apps/procedimientos/views.py` línea ~321
```python
# AGREGAR después de paciente.creado_por:
paciente.estado = Paciente.Estado.ADMITIDO
```

## 🎯 RESULTADO

### Antes:
```
Registro → ACTIVO → No aparece pendientes ❌
Asignación → Sin validar → Admisión no vinculada ❌
Grupos → Vacíos ❌
```

### Después:
```
Registro → ADMITIDO → Aparece pendientes ✅
Valoración → Valida → Admisión vinculada ✅
Grupos → Muestran pacientes ✅
```
