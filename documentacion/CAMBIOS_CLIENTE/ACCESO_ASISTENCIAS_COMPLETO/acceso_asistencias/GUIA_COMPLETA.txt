# 📋 GUÍA COMPLETA: Sistema de Asistencias con Accesos

## 🎯 OBJETIVO

Crear accesos para que los terapeutas puedan **tomar asistencia diaria** de sus grupos, mostrando solo pacientes con **admisiones vigentes**.

---

## 📦 COMPONENTES

### 1. Modelo AsistenciaPaciente
- Registro diario de asistencias
- Relación con paciente, grupo, asignación
- Campos: asistió, justificada, observaciones, horarios

### 2. Vista control_asistencia_grupo
- Muestra pacientes con admisión vigente
- Formulario para marcar asistencia
- Actualiza contador en admisión

### 3. Vista lista_grupos_terapeuta
- "Mis Grupos" del terapeuta
- Acceso rápido a tomar asistencia

### 4. Vista historial_asistencia_paciente
- Historial completo del paciente
- Estadísticas de cumplimiento

### 5. URLs
- `/grupos/<id>/asistencia/` - Tomar asistencia
- `/mis-grupos/` - Grupos del terapeuta
- `/pacientes/<id>/historial-asistencia/` - Historial

### 6. Accesos UI
- Botón en detalle del grupo
- Menú "Mis Grupos" en navbar
- Dashboard terapeuta
- Tabla de pacientes

## ✅ VALIDACIONES IMPLEMENTADAS

### Admisión Vigente:
```python
# Solo muestra pacientes si:
- admision_terapia existe
- estado == 'VIGENTE'
- fecha_inicio <= hoy <= fecha_fin
```

### Una asistencia por día:
```python
# unique_together en modelo
unique_together = [['paciente', 'grupo', 'fecha']]
```

### Actualización automática:
```python
# Si asistió, incrementa contador
if asistio:
    admision.cantidad_realizada += 1
    admision.save()
```

### Import error:
```python

# Solución: Verificar que el modelo esté en models.py
```
