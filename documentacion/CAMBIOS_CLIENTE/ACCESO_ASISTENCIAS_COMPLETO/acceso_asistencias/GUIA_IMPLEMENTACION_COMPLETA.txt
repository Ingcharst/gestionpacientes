# 🎯 GUÍA COMPLETA: Accesos al Registro de Asistencias

## 📋 PROBLEMA

No puedes acceder al registro de asistencias desde ningún lugar de la aplicación.

## ✅ SOLUCIÓN

Crear múltiples puntos de acceso para que los terapeutas puedan:
1. Ver sus grupos desde un menú "Mis Grupos"
2. Acceder al registro de asistencia con 1 clic
3. Ver solo pacientes con admisión vigente
4. Registrar asistencia diaria

### PASO 2: Agregar vista "Mis Grupos" (3 min)

**Archivo:** `apps/grupos/views.py`

**Copiar:** Contenido completo de `vista_mis_grupos.py`

O usar versión corta:

```python
@login_required
def mis_grupos(request):
    fecha_hoy = date.today()
    
    grupos_base = GrupoTerapeutico.objects.filter(
        terapeuta_responsable=request.user,
        estado='ACTIVO'
    )
    
    grupos_procesados = []
    
    for grupo in grupos_base:
        asignaciones = AsignacionGrupo.objects.filter(
            grupo=grupo,
            estado='ACTIVA'
        ).select_related('paciente', 'admision_terapia')
        
        # Filtrar pacientes con admisión vigente
        pacientes_vigentes = []
        for asig in asignaciones:
            if asig.admision_terapia:
                admision = asig.admision_terapia
                if (admision.estado == 'VIGENTE' and
                    admision.fecha_inicio <= fecha_hoy <= admision.fecha_fin):
                    pacientes_vigentes.append(asig)
        
        grupo.total_pacientes_vigentes = len(pacientes_vigentes)
        grupo.pacientes_sample = pacientes_vigentes[:3]
        grupos_procesados.append(grupo)
    
    return render(request, 'grupos/mis_grupos.html', {
        'grupos': grupos_procesados,
        'fecha_hoy': fecha_hoy,
    })
```

```python
@login_required
def grupo_detalle(request, pk):
    grupo = get_object_or_404(GrupoTerapeutico, pk=pk)
    fecha_hoy = date.today()
    
    asignaciones = AsignacionGrupo.objects.filter(
        grupo=grupo,
        estado='ACTIVA'
    ).select_related('paciente', 'admision_terapia')
    
    # ✅ SEPARAR por vigencia de admisión
    pacientes_con_admision = []
    pacientes_sin_admision = []
    
    for asig in asignaciones:
        if asig.admision_terapia:
            admision = asig.admision_terapia
            if (admision.estado == 'VIGENTE' and
                admision.fecha_inicio <= fecha_hoy <= admision.fecha_fin):
                pacientes_con_admision.append(asig)
            else:
                pacientes_sin_admision.append(asig)
        else:
            pacientes_sin_admision.append(asig)
    
    return render(request, 'grupos/detalle_grupo.html', {
        'grupo': grupo,
        'pacientes_con_admision': pacientes_con_admision,
        'pacientes_sin_admision': pacientes_sin_admision,
        'pacientes_activos': len(pacientes_con_admision),
        'fecha_hoy': fecha_hoy,
    })
```

## 🆘 TROUBLESHOOTING

### No aparece en navbar
```
Verificar:
- URL correcta: {% url 'grupos:mis_grupos' %}
- Namespace 'grupos' definido
- Usuario autenticado
```

### Página "Mis Grupos" vacía
```
Verificar:
- Usuario es terapeuta_responsable de algún grupo
- Estado del grupo es 'ACTIVO'
- Query en vista correcta
```

### No muestra pacientes
```
Verificar:
- Asignaciones estado 'ACTIVA'
- Pacientes tienen admision_terapia
- Admisión estado 'VIGENTE'
- Fechas inicio/fin válidas
```

### Botón no redirige
```
Verificar:
- URL control_asistencia_grupo existe
- Parámetro grupo_id correcto
- Vista implementada
```
