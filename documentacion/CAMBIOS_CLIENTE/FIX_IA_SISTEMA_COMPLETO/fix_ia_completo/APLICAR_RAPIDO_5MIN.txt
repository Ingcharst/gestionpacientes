## 🔴 PROBLEMA

IA dice "Sin valoraciones" aunque SÍ existen valoraciones registradas.

**Causa:** Sistema busca modelo antiguo `Valoracion Inicial`, ahora usa `ValoracionProfesional` (múltiples).

### Paso 2: Actualizar vista recomendación (2 min)

**Archivo:** `apps/grupos/views.py`

**Buscar la función** `recomendar_grupos_paciente`:

```python
@login_required
def recomendar_grupos_paciente(request, pk):
    """Vista de recomendación IA - ACTUALIZADA"""
    from apps.procedimientos.models import Paciente, ValoracionProfesional
    from apps.ml_models.predictor import GrupoRecomendador
    from django.shortcuts import render, redirect, get_object_or_404
    from django.contrib import messages
    
    paciente = get_object_or_404(Paciente, pk=pk)
    
    # ✅ CAMBIO: Obtener TODAS las valoraciones (no solo una)
    valoraciones = ValoracionProfesional.objects.filter(
        paciente=paciente
    ).select_related('terapia', 'terapeuta')
    
    # ✅ CAMBIO: Verificar con .exists()
    if not valoraciones.exists():
        messages.warning(request,
            'El paciente no tiene valoraciones registradas. '
            'Debe completar al menos una valoración por terapeuta.'
        )
        return redirect('procedimientos:valoraciones_paciente', pk=pk)
    
    # ✅ CAMBIO: Pasar valoraciones al recomendador
    recomendador = GrupoRecomendador()
    resultado = recomendador.recomendar_grupos(
        paciente=paciente,
        valoraciones=valoraciones  # Pasar QuerySet completo
    )
    
    if resultado.get('error'):
        messages.error(request, resultado.get('mensaje'))
        return redirect('procedimientos:paciente_detail', pk=pk)
    
    context = {
        'paciente': paciente,
        'valoraciones': valoraciones,
        'recomendaciones': resultado['recomendaciones'],
        'mensaje': resultado['mensaje'],
    }
    
    return render(request, 'grupos/recomendar_grupos.html', context)
```
