# 🔴 PROBLEMA IDENTIFICADO: Campos sin controles en el formulario

## ❌ SÍNTOMA

Los siguientes campos aparecen SOLO con etiquetas (labels) pero SIN controles de entrada:

### Información Médica:
- Alergias
- Medicamentos Actuales  
- EPS

### Fechas de Atención:
- Fecha de Ingreso
- Fecha de Alta (Opcional)
- Motivo de Inactividad (Opcional)

### Observaciones:
- Observaciones Generales
- Necesidades Especiales

---

## 🔍 CAUSA DEL PROBLEMA

**Archivo:** `apps/procedimientos/forms.py`

### Error 1: Sintaxis rota en línea 41-44

```python
# ❌ INCORRECTO:
'diagnostico_principal': forms.TextInput(attrs={
    'class': 'form-control',
    'placeholder': 'Solo si no está en catálogo (ej: Z99.9)'
}),         'fecha_nacimiento': forms.DateInput(attrs={'type': 'date', 'class': 'form-control'}),
```

**Problema:** 
- Falta salto de línea entre campos
- Confunde al parser de Python
- Causa que algunos widgets no se procesen

---

### Error 2: Widget duplicado para diagnostico_principal

```python
# Línea 41-43
'diagnostico_principal': forms.TextInput(...),

# Línea 49 (duplicado)
'diagnostico_principal': forms.Textarea(...),
```

**Problema:** Python solo toma el último, pero el primero rompe la sintaxis

---

### Error 3: Falta widget para EPS

```python
widgets = {
    # ... otros campos ...
    'alergias': forms.Textarea(...),
    'medicamentos': forms.Textarea(...),
    # ❌ FALTA: 'eps': forms.TextInput(...)
}
```

**Problema:** Sin widget explícito, usa widget por defecto del modelo sin clases CSS
