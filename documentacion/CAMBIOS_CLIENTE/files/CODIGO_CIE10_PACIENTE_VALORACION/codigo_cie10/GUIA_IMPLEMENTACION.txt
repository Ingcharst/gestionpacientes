## 🎯 CASOS DE USO

### Caso 1: Registro con diagnóstico conocido
```
1. Registrar paciente
2. Seleccionar código CIE-10 (ej: F84.0 - Autismo infantil)
3. Guardar
4. Campo se guarda en Paciente.codigo_enfermedad
```

### Caso 2: Valoración con diagnóstico específico
```
1. Terapeuta evalúa paciente
2. En valoración selecciona código CIE-10
3. Puede ser diferente al del registro inicial
4. Cada terapeuta asigna según su evaluación
5. Campo se guarda en ValoracionProfesional.codigo_cie10
```

### Caso 3: Sin diagnóstico
```
1. Registrar paciente sin código (campo opcional)
2. Crear valoraciones sin código (campo opcional)
3. Asignar posteriormente cuando se confirme diagnóstico
```

## 🔧 SOLUCIÓN A PROBLEMAS

### Problema: Select2 no funciona

**Verificar:**
1. jQuery cargado antes de Select2
2. CDN de Select2 correcto
3. ID del campo correcto: `#id_codigo_enfermedad` o `#id_codigo_cie10`

**Solución:**
```html
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/select2@4.1.0-rc.0/dist/js/select2.min.js"></script>
```
