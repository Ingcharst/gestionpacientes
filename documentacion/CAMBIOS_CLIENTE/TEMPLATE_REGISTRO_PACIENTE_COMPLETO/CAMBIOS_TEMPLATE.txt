## 🔧 REQUERIMIENTOS EN BACKEND

Para que el template funcione completamente, necesitas agregar en las vistas:

### 1. **API de búsqueda CIE-10**

**Archivo:** `apps/procedimientos/views.py`

```python
from django.http import JsonResponse
from django.db.models import Q
from .models import CodigoCIE10

def api_buscar_cie10(request):
    """API para búsqueda de códigos CIE-10"""
    query = request.GET.get('q', '').strip()
    
    if len(query) < 2:
        return JsonResponse({'resultados': []})
    
    # Buscar por código o descripción
    codigos = CodigoCIE10.objects.filter(
        Q(codigo__icontains=query) | 
        Q(descripcion__icontains=query),
        activo=True
    ).order_by('codigo')[:20]
    
    resultados = [{
        'id': c.id,
        'codigo': c.codigo,
        'descripcion': c.descripcion
    } for c in codigos]
    
    return JsonResponse({'resultados': resultados})
```

### 3. **Vista de registro de paciente**

**Archivo:** `apps/procedimientos/views.py`

```python
from .forms import PacienteForm

def registrar_paciente(request):
    if request.method == 'POST':
        form = PacienteForm(request.POST, request.FILES)
        if form.is_valid():
            paciente = form.save(commit=False)
            paciente.creado_por = request.user
            paciente.save()
            
            messages.success(request, 'Paciente registrado exitosamente')
            return redirect('procedimientos:paciente_list')
    else:
        form = PacienteForm()
    
    return render(request, 'procedimientos/registrar_paciente.html', {
        'form': form,
        'titulo': 'Registrar Nuevo Paciente',
        'mostrar_firma': True  # Si usas firma digital
    })
```

## 🆘 TROUBLESHOOTING

### Problema: Búsqueda no funciona

**Verificar:**
1. URL de API correcta en JavaScript (línea 527)
2. API existe y retorna JSON
3. Console del navegador (F12) para errores

**Solución:**
```javascript
// Verificar URL en línea 527
fetch(`/procedimientos/api/buscar-cie10/?q=${query}`)
```

### Problema: No aparecen códigos

**Verificar:**
1. Existen códigos CIE-10 en BD
2. Campo `activo=True` en códigos
3. Query mínimo de 2 caracteres

**Cargar códigos:**
```bash
python manage.py cargar_codigos_cie10
```
