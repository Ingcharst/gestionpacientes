## INSTALACIÓN RÁPIDA

### 1. Descomprimir
```bash
unzip TEMPLATES_FASE2.zip
```

### 2. Copiar templates completos
```bash
# Procedimientos
cp TEMPLATES_FASE2/procedimientos/*.html apps/procedimientos/templates/procedimientos/

# Grupos
cp TEMPLATES_FASE2/grupos/*.html apps/grupos/templates/grupos/

# Alertas
cp TEMPLATES_FASE2/alertas/*.html apps/alertas/templates/alertas/
# Renombrar: dashboard_alertas.html → dashboard.html

# Base
cp TEMPLATES_FASE2/base/base.html apps/base/templates/base/
# O donde tengas tu template base
```

### 3. Copiar templates compactos
Abrir **TEMPLATES_RESTANTES.txt** y copiar cada sección al archivo correspondiente.

### 4. Verificar
```bash
python manage.py runserver
# Probar: http://localhost:8000/procedimientos/pacientes/registrar/
```

## TROUBLESHOOTING

### ❌ Template no encontrado
```
TemplateDoesNotExist: procedimientos/registrar_paciente.html
```
**Solución:** Verificar ruta exacta y nombre archivo

### ❌ Static files no cargan
**Solución:** 
```bash
python manage.py collectstatic
```

### ❌ Select2 no funciona
**Solución:** Verificar que jQuery carga ANTES de Select2

### ❌ URL no encontrada
**Solución:** Verificar namespace en urls.py:
```python
app_name = 'procedimientos'  # Requerido
```
