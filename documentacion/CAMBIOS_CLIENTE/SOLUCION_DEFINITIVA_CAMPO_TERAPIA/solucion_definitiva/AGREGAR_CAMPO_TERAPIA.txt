### Opción B: Script Python (Para muchos grupos)

**Crear archivo:** `asignar_terapias.py` en la raíz del proyecto

```python
# asignar_terapias.py
import os
import django

os.environ.setdefault('DJANGO_SETTINGS_MODULE', 'config.settings')
django.setup()

from apps.grupos.models import GrupoTerapeutico
from apps.terapias.models import Terapia

# Ejemplo: Asignar terapias según nombre del grupo
terapia_lenguaje = Terapia.objects.get(nombre__icontains='lenguaje')
terapia_ocupacional = Terapia.objects.get(nombre__icontains='ocupacional')
terapia_fisica = Terapia.objects.get(nombre__icontains='física')

# Asignar según coincidencias en nombre
grupos_lenguaje = GrupoTerapeutico.objects.filter(
    nombre__icontains='lenguaje'
)
grupos_lenguaje.update(terapia=terapia_lenguaje)

grupos_ocupacional = GrupoTerapeutico.objects.filter(
    nombre__icontains='ocupacional'
)
grupos_ocupacional.update(terapia=terapia_ocupacional)

print(f"Actualizado {grupos_lenguaje.count()} grupos de lenguaje")
print(f"Actualizado {grupos_ocupacional.count()} grupos ocupacionales")

# Listar grupos sin terapia asignada
sin_terapia = GrupoTerapeutico.objects.filter(terapia__isnull=True)
print(f"\nGrupos sin terapia: {sin_terapia.count()}")
for grupo in sin_terapia:
    print(f"  - {grupo.nombre}")
```

**Ejecutar:**
```bash
python asignar_terapias.py
```

### Opción C: Comando Django (Más profesional)

**Crear:** `apps/grupos/management/commands/asignar_terapias.py`

```python
from django.core.management.base import BaseCommand
from apps.grupos.models import GrupoTerapeutico
from apps.terapias.models import Terapia

class Command(BaseCommand):
    help = 'Asigna terapias a grupos existentes'
    
    def handle(self, *args, **options):
        sin_terapia = GrupoTerapeutico.objects.filter(terapia__isnull=True)
        
        self.stdout.write(f"Grupos sin terapia: {sin_terapia.count()}")
        
        if sin_terapia.count() == 0:
            self.stdout.write(self.style.SUCCESS('Todos los grupos tienen terapia asignada'))
            return
        
        # Listar terapias disponibles
        terapias = Terapia.objects.all()
        self.stdout.write("\nTerapias disponibles:")
        for i, terapia in enumerate(terapias, 1):
            self.stdout.write(f"  {i}. {terapia.nombre}")
        
        # Mostrar grupos sin terapia
        self.stdout.write("\nGrupos sin terapia:")
        for grupo in sin_terapia:
            self.stdout.write(f"  - {grupo.nombre}")
        
        self.stdout.write(self.style.WARNING(
            '\nAsigna terapias manualmente en el admin o personaliza este comando'
        ))
```

**Ejecutar:**
```bash
python manage.py asignar_terapias
```
